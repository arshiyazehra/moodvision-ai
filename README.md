# 🧠 MoodVision AI

### AI-Powered Facial Emotion Recognition

MoodVision AI is an intelligent web application that uses Artificial Intelligence and Computer Vision to analyze facial expressions and detect human emotions.

https://moodvision-ai-f3mx.onrender.com

## ✨ Features

- 📷 Facial image analysis
- 🧠 AI-powered emotion recognition
- 😊 Detects the dominant emotion
- 📊 Displays emotion analysis results
- 🔄 Analyze Again functionality
- ⚡ Interactive and easy-to-use interface
- 📱 Responsive design

## ⚙️ How It Works

1. The user provides a facial image.
2. The image is sent to the Flask backend.
3. DeepFace analyzes the facial expression.
4. The AI identifies the dominant emotion.
5. The result is displayed to the user.
